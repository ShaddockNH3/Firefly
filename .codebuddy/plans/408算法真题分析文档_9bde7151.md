## 用户需求

在现有考研笔记《考研冲刺前的总结 —— 综合错题》的「代码随想录简单题注意题速刷」小节末尾（第 16726 行之后、`## 408 深度注意` 之前）新增一份独立文档，标题固定为 `### DS-4.1f-1017 408 算法真题分析`。

**题号说明（重要修正）**：408 数据结构算法设计题**不固定在第 41 题**。试卷综合应用题区间为 41–47，其中数据结构占 41、42 两题，算法设计题可能落在 41，也可能落在 42（例：2011 年第 41 题为散列表查找，算法设计题为第 42 题「两个等长升序序列求中位数」）。因此文档必须以「当年试卷中真正的算法设计题」为准逐年界定题号，不得默认 41 题。

## 文档概述

覆盖 2009–2025 共 17 套 408 数据结构算法真题（每年一道算法设计题，题号为 41 或 42）。不再按年份平铺，而是先按考点归一为若干「408 xx 算法专题」，再在专题内按年份列出真题。2023–2025 三套通过公开资料检索获得，无法确证之处逐条标注「待核验」。

## 核心功能

- **题号界定**：逐年确认算法设计题所在题号（41 或 42），并在总览表与每条真题标题中显式标出「20xx 年第 4x 题」；若某年数据结构 41、42 两题都含算法设计成分（如要求写出算法并分析复杂度），以「算法设计题」为准，必要时双列并注明主次。
- **专题划分**：数组与原地操作、链表、二叉树、图、查找与排序、字符串、栈队列与哈希等；每题归入唯一主专题，避免交叉重复。
- **真题条目**：给出题目原文（保留数据规模、函数接口、返回值要求等关键约束），随后分别写「次优解」与「最优解」的大致思路，并各自标注时间复杂度、空间复杂度；不写 C 代码。
- **同源题单**：每个专题后附「代码随想录 / LeetCode 同源题目」，按考点同源而非题名相似进行映射，覆盖简单与中等难度，每专题不少于 8–15 题，标注题号与一句话对应理由。
- **总览统计**：开头给出「专题 × 年份」考频矩阵，单元格格式为「年份（第 4x 题）」；附 41/42 题号分布与高频结论，便于快速定位与二轮复习。
- **排版效果**：沿用笔记现有中文口语化风格与标题层级，仅使用标题、加粗、列表、表格，在博客中渲染正常、锚点不与全文冲突。

## 实现方案

1. **题源层**：建立 17 年清单（年份 / **题号 41 或 42** / 一句话题意 / 主专题 / 来源链接 / 可信度）。题号必须由题源确认，禁止按「惯例 41 题」推定；若检索到的题源只给题面未标题号，则通过该年试卷题序（41 散列表、42 中位数 这类相邻题内容）反推核对。2009–2022 以公开真题为主，并核对本笔记已有「真题 2 刷」章节是否留下线索（已确认：该章节只记录选择题错题，无算法题原文，不可直接摘录）。2023–2025 至少两个独立来源交叉比对（解析站、教育类站点、GitHub 真题仓库等），冲突或缺失时保留最可信版本并标「待核验」。
2. **归类层**：按「主导解法」而非「题干表象」归专题（如循环左移归数组逆置、主元素归计数/摩尔投票、WPL 归二叉树遍历）。生成专题 × 年份矩阵，确保 17 年全覆盖、无遗漏、无重复；矩阵中同时体现题号，便于自查「有没有把 42 题漏掉」。
3. **撰写层**：统一模板 —— 年份与题号 → 题干原文 → 次优解（思路 + 时间/空间）→ 最优解（思路 + 时间/空间）→ 一句话关键坑点（简短）→ 同源题单。复杂度必须与所列思路严格对应，禁止出现与解法不匹配的泛化标注。
4. **题单层**：只收简单/中等，每题给「题号 + 名称 + 对应真题考点」三元组；图/树/链表等 408 高频专题适当加量，回溯、DP 等非 408 算法题风格的内容不纳入。
5. **写入层**：在第 16726 行之后插入，保留原 3 行正文不动；层级为 `##` → `### DS-4.1f-1017` → `#### 专题` → 年份加粗（含题号），专题使用 `####` 以与 `### DS-4.1f-1017` 形成正确父子关系。

## 实现要点

- **题号正确性**：17 套里凡算法题不在 41 的年份，必须在正文和总览表中体现，否则与试卷结构不符；写作时先列「年份 → 题号」对照，再动笔写专题。
- **正确性优先**：408 算法题的「最优解」常依赖隐性约束（一趟完成、O(1) 额外空间、不许改链表结构），题干原文必须保留这些约束，否则最优解判定会出错。
- **复杂度对照**：同一题两档解法要体现真实差异（如 O(n) 空间 → O(1) 空间、O(n log n) → O(n)），否则失去「次优/最优」对比价值。
- **体量控制**：预计 700–1100 行，建议分两步写入（先骨架+总览，再逐专题追加），每次追加后校验标题层级、表格闭合与空行。
- **渲染安全**：不引入 MDX、HTML 标签、内嵌图片；表格单元格内不用 `|` 和换行；标题避免与全文已有同名标题重复导致锚点冲突。
- **影响面控制**：只做插入，不重排、不改写插入点以外任何既有内容，保持与原笔记格式一致。
