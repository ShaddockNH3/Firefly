# 最后的冲刺

考研最后 40 天了，突然感觉自己回到了最好的状态。

等下睡觉，睡醒了然后去按照计划推进下去。

我觉得我可以！

还有就是，突然又找到了动力。

相信自己可以成功。

以及——

熬下去，熬赢就是胜利。

现在感觉自己有点过拟合了，不过还好就是了。

写卷子的心态可能还需要解决，碰到不会的题别想着一下问 AI，还是先自己走走路子，自己的路子也许就是对的呢（而且大概率就是对的）。

还有什么吗，没有了。

加油！

冲刺！

反正不可能再像高考前那样摆烂了。

以后 3 天 2 张卷子算标配吧，就这样了。
