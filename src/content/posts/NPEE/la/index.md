## 前言

## 行列式

### 范德蒙行列式

形式需要记住。

### 行列式计算

1. 从行列式中提取常数，需要变为 k^n
2. A* 的行列式值为 A行列式^(n-1)
3. 分块矩阵的行列式，需要注意如果是主对角线，那么不需要 -1，如果是副对角线，那么是 -1^(mn)

### 行列式串联

可以和求特征向量联系起来来简化计算，典例为 2009 线代真题。

### 代数余子式求和

原理：$\sum_{k=1}^n a_{ik} A_{jk} = \begin{cases} |A|, & i=j \\ 0, & i \neq j \end{cases}$。

遇到类似计算“$a A_{11} + b A_{12} + c A_{13}$”的题目，本质就是把矩阵 $A$ 的第 $1$ 行元素换成 $(a, b, c)$ 后的新矩阵行列式。

### 伴随矩阵的行列式与基本公式

$A A^* = A^* A = |A| E$。

$|A^*| = |A|^{n-1}$。

$|kA^*| = k^n |A|^{n-1}$（别把 $k$ 提出来时漏了 $n$ 次方）。

还可以注意，如果题目给了具体的条件，例如 aij = -Aij，那么可以通过转换为抽象矩阵来理解。

### 特征值与行列式 / 迹的关系

$|A| = \prod_{i=1}^n \lambda_i$（所有特征值的乘积）。

$\text{tr}(A) = \sum_{i=1}^n a_{ii} = \sum_{i=1}^n \lambda_i$（所有对角元之和等于特征值之和）。

## 矩阵

### 矩阵的逆与回代

尤其要注意，如果不满秩则不可逆，如果题目条件里出现了不可逆的矩阵但是要解，可以注意一下回代。

即 XA=xxxA，那么X-xxx A=0，前者不一定为0。

### 秩不等式

$r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n-1 \\ 0, & r(A) < n-1 \end{cases}$

经典的几个秩不等式，尤其是 AB=0 这个不等式要会。

对于分块矩阵的初等变换，要注意是不是可逆变换，右乘只能对列变换左乘只能对行变换。

此外，利用类似 “夹逼定理” 的思路证明某个矩阵秩的值。

$r(A+B) \le r(A) + r(B)$。

$r(AB) \le \min(r(A), r(B))$。

若 $AB = O$，则 $r(A) + r(B) \le n$（$n$ 为 $A$ 的列数 / $B$ 的行数）。

西尔维斯特不等式：$r(A) + r(B) - n \le r(AB)$。

需要注意，对于西尔韦斯特不等式，如果 A 和 B 形状不一样，那么是 - s，其中 s 是 A 的列，B 的行。

### AB=A+B 可以怎么用

同时 + E 可以化简成乘积的形式。

### AB=BA 可以怎么用

利用特征值。

## 向量组

### 向量组辨析

行等价可以推导出等价，列等价可以推导出等价，只有等价推导不出来任何东西，只能说明秩相等。

假设 A 和 B 列等价，那么 AQ=B，C 和 D 行等价，那么 PC=D。

对于矩阵 A 和 B，假设 A 和 B 行等价，那么 AX=0 和 BX=0 同解。

判断向量组 a1，a2，an 是否线性相关，本质上是看等式 x1a1+x2a2+…=0 时候有零解，所以拼成矩阵 A，本质就是齐次线性方程 Ax=0。如果只有零解，那么线性无关，有非零解，所以线性相关。而 A 做行变换的时候，可以保证解不变。

对矩阵 A 做初等列变换，那么矩阵列的秩保持不变（也就是说列等价），变了的东西是列向量的线性系数表达。

对矩阵 A 做初等行变换，那么矩阵行的秩保持不变（也就是行等价），系数关系是保留的，但是里面的东西变了。

m 个 n 维向量一定是线性相关向量组（m > n）

### 向量组等价 vs 矩阵等价

两向量组等价 $\iff$ 可以相互线性表出 $\iff$ r(I) = r(II) = r(I, II)。

向量组等价能推出矩阵等价，但矩阵等价推不出向量组等价。

### 证明向量组线性无关

利用 k1a1+k2a2+…=0，即定义证明秩不等式，且对于线性无关而言，x1，x2，x3 必须是三个独立的数。

### 施密特正交化

设无关向量组为 $\alpha_1, \alpha_2, \alpha_3$：

$\beta_1 = \alpha_1$

$\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)} \beta_1$

$\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)} \beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)} \beta_2$

## 方程组

### 方程组串联

对方程组 Ax=0，如果方程组有唯一解，那么解必然为 0，如果有无穷解，则计算 R(A)，通解的个数为 n-R(A)。

对行列式而言，可以通过计算 A 的行列式来判断 A 是否有唯一解。

对矩阵而言，如果 x 是一个矩阵，那么可以通过变换解出 n 组解，需要注意这些解的 k 是独立的。

对于特征值而言，显然有 n-R(A) 个特征值为 0 的特征向量，且特征向量为通解。

对于方程组 Ax=b，如果方程组有唯一解，那么 A 的行列式必不为 0，即 R(A)=R(A,b)
=n。

如果有无穷解，那么 R(A)=R(A,b)<n。

### 解 AB=E

假设已知 A，如何求解出所有的 B，只需要按照解方程组的做法，把每一列都解出来即可。

具体可以表现为：

将 [A, E]，变换为 [E, P]，然后逐个分析即可。

### 解的结构补充

齐次方程通解：$c_1 \xi_1 + \dots + c_{n-r} \xi_{n-r}$。
非齐次方程通解：$\eta^* + c_1 \xi_1 + \dots + c_{n-r} \xi_{n-r}$（$\eta^*$ 为非齐次特解）。

解的线性组合性质：若 $\eta_1, \eta_2$ 是 $Ax=b$ 的解，则 $\eta_1 - \eta_2$ 是齐次方程 $Ax=0$ 的解；$\frac{\eta_1 + \eta_2}{2}$ 依然是 $Ax=b$ 的解（系数和为 1 则为非齐次解，系数和为 0 则为齐次解）。

### 公共解与同解

同解：$Ax=0$ 与 $Bx=0$ 同解 $\iff$ 解空间相同 $\iff r(A) = r(B) = r\begin{pmatrix} A \\ B \end{pmatrix}$。

公共解：联立求解 $\begin{pmatrix} A \\ B \end{pmatrix} x = 0$，或者求出其中一个方程的通解代入另一个方程检验。

## 特征值与特征向量

### 判断相似性

$n$ 阶矩阵 $A$ 可相似对角化 $\iff$ $A$ 有 $n$ 个线性无关的特征向量。

$\iff$ 每个 $k_i$ 重特征值，其几何重数 $n - r(\lambda_i E - A) = k_i$（即基础解系包含的向量数等于重数）。

充分条件：$n$ 阶矩阵有 $n$ 个互不相同的特征值；或 $A$ 为实对称矩阵。

若 $A \sim B$，则：

特征值相同，$|A| = |B|$，$\text{tr}(A) = \text{tr}(B)$。

秩相等：$r(A) = r(B)$。

特征多项式相同：$|\lambda E - A| = |\lambda E - B|$。

反之不成立！

### 求特征值和特征向量的方法

略去，但是需要注意在解方程的时候必须把每个式子写出来，这样可以大幅降低错误率。

### 秩为 1 的特征值与特征向量

若 $A = \alpha \beta^T$（$\alpha, \beta$ 为非零列向量）：

$r(A) = 1$。

$\text{tr}(A) = \beta^T \alpha$。

特征值为：$\lambda_1 = \text{tr}(A) = \alpha^T \beta$，其余 $n-1$ 个特征值均为 $0$。

$A^2 = (\beta^T \alpha) A = \text{tr}(A) A$。

此外还可以注意 $AA*$ 的相关性质，要记住 AA*=0，当 A 不满秩的时候。

### 矩阵变换与特征值的变换情况

通过 aE + B 的方式化简特征值的求解。

### 两边同时乘上某些东西求特征值

例如 Aa，然后同时乘上一个 A 可以得到什么，常和证明线性无关一起用。

### 实对称矩阵

特征值全为实数。

不同特征值对应的特征向量天然正交！

$k$ 重特征根必有 $k$ 个线性无关的特征向量（实对称矩阵必可对角化！）。

必存在正交矩阵 $Q$，使得 $Q^T A Q = Q^{-1} A Q = \Lambda$。

#### 向量正交

如果是实对称矩阵。

假设已知 3 个特征值不同，知道 2 个特征向量，那么可以直接通过正交性求出第 3 个特征向量。

假设已知有 1 个特征值的特征向量，另外两个特征值相同，那么也可以通过正交求出第 2、3 个特征向量。

使用这个性质的前提是为实对称矩阵。

### 相似的传递性

通过相似的传递性可以求一些题目（比较经典）。

## 二次型

### 合同

如果一个矩阵是实对称矩阵，那么相似可以推出合同。

等价：同型且 $r(A) = r(B)$（只需可逆变换 $PAQ=B$）。

合同：$C^T A C = B$（正负惯性指数相同 $\iff$ 二次型相同规范型）。

相似：$P^{-1} A P = B$（特征值完全相同且能对角化程度相同）。
对于实对称矩阵：相似 $\implies$ 特征值相同 $\implies$ 正负特征值个数相同 $\implies$ 正负惯性指数相同 $\implies$ 合同！

（即实对称矩阵相似必合同，反之不成立）。

### 正定矩阵判定

二次型正定 $\iff$ 矩阵 $A$ 正定。

注意 A 是实对称矩阵

充要条件：

特征值全部严格大于 $0$（$\lambda_i > 0$）。

顺序主子式全大于 $0$（各阶行列式 $D_k > 0$）。

正惯性指数 $p = n$。

合同于单位阵 $E$（即存在可逆阵 $C$ 使得 $A = C^T C$）。

必要条件（用来快速排除选项）：主对角元全大于 $0$（$a_{ii} > 0$），且 $|A| > 0$。
